# Landing page do curso gratuito

Endereço: `/morte-encefalica.html`. Página pública em HTML e CSS, no mesmo projeto Vercel da plataforma.

## Cadastro e conteúdo

- As duas chamadas de participação usam `index.html?cadastro=1`, que seleciona a aba Criar conta antes da verificação de sessão existente.
- O acesso de quem já tem conta continua pelo login normal. Não houve alteração nos endpoints de autenticação ou nas regras de acesso aos cursos.
- Os oito eixos são o programa previsto; a página informa que novas aulas são adicionadas progressivamente. Não há promessa de certificado, habilitação, duração final ou parceria institucional.
- A apostila fornecida foi usada para organizar o programa. O PDF não foi publicado com a landing page.
